# Changelog

All notable changes to the **Davarus Bell Platform** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-09-18
### Added
- Enterprise GitHub infrastructure (`.github/workflows/ci.yml`, CODEOWNERS, Issue templates, PR templates).
- Interactive Live Developer Preview Hub (`app/public/dev.html`).
- Architecture Decision Records (`docs/adr/0001-cloudflare-workers-and-hono.md`, `docs/adr/0002-d1-sqlite-crm-persistence.md`).
- Multi-viewport responsive preview suite for desktop & mobile.

## [1.0.0] - 2026-09-18
### Added
- Initial public release of Davarus Bell Brand OS platform.
- Cloudflare Worker backend powered by Hono (`/api/leads`, `/api/health`).
- D1 SQLite Database schema for Lead capture, Appointments, and CRM activity log.
- 5 Responsive Web Funnel Pages (`index.html`, `buy.html`, `sell.html`, `relocate.html`, `speaking.html`).
- Sales pitch deck slides, proposal, media speaker kit, and onboarding intake checklist.
